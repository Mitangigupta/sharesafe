In-Situ Workflow Sequence

The ShareSafe extension intercepts accidental data leakage at the moment of creation, avoiding the need to manually export files or navigate away from active browser tabs:

1

In-Browser Text Selection / Compose Focus

Select text on any webpage, focus a message draft in WhatsApp/Gmail, or drop a document to attach.

2

Context Menu or Automated Shield Trigger

Right-click "Scan with ShareSafe", click "Scan Compose Box", or trigger automated upload screening.

3

Checksum & Risk Verification

Dispatched to /api/scan-text or /api/inspect-file to evaluate mathematical checksums (Verhoeff, Luhn) and QR threats in under 50ms.

4

Defensive Masking & Pre-Upload Modal

Popup badge alerts risk level, or an in-page modal pauses file upload allowing 1-click Studio redirection before files leave the device.

Client Privacy Guarantees

Zero Surveillance

No keyloggers, passive sniffing, or DOM tracking. Only processes text explicitly selected or files attached by the user.

Scoped Permissions

Restricted strictly to contextMenus, storage, and activeTab. Zero access to browsing history or global URLs.

Ephemeral Caching

Findings reside exclusively in chrome.storage.session, which is automatically purged when the browser closes.

Phase 3: Automated Pre-Upload File Shield

Real-time file interception screening documents and images before they are uploaded to WhatsApp Web, Gmail, or cloud services.

Users frequently leak sensitive credentials not by typing them in text, but by attaching raw identity documents, invoices, or screenshots into chat windows. Phase 3 introduces automated pre-upload screening: the extension automatically intercepts attachments across three distinct entry points:

A
File Picker Interception
Hooks the native DOM change event on <input type="file"> elements whenever the user clicks the attach paperclip in WhatsApp Web or Gmail.
B
Drag-and-Drop Capture
Intercepts the browser drop event when files are dragged directly from desktop/File Explorer into active chat areas.
C
Clipboard Screenshot Paste
Intercepts paste events carrying image files (e.g. Snipping Tool screenshots or copied PDF clippings).
Scenario A: Clean File Upload Zero Friction
When an audited document contains no PII, financial numbers, or leaking QR payloads, the ShareSafe shield approves the upload in under 50ms. A subtle green status pill confirms validation and the platform sends the file without interruption.
Scenario B: Sensitive File Intercepted Upload Paused
When sensitive credentials (Aadhaar UID, Credit Card, PAN, secret tokens) are discovered, the upload is immediately halted. An in-page defensive modal allows the user to Cancel, Redact in ShareSafe Studio, or deliberately override.
