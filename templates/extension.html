Attachment Redaction Workflow

WhatsApp • Gmail
1

Capture-Phase Interception

User attaches a photo, image, or PDF on WhatsApp Web or Gmail. The extension intercepts the file input in the capture phase before the platform can transmit it.

2

Local OCR & Auto-Redaction by Default

Extracted text is scanned via Verhoeff/Luhn checksum algorithms. All sensitive entities are automatically queued for blackout redaction with 0 text stream leakage.

3

In-Situ Review, Selective Undo & File Swap

Review detected items with 1-click selective undo. The sanitized copy is verified non-recoverable and injected via DataTransfer while the raw original is discarded.
