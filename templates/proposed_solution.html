Dual-Pillar Privacy Architecture

ShareSafe: Sovereign Document Sanitization and Context-Aware AI Guidance

An end-to-end, on-device platform uniting deterministic entity detection, irreversible multi-style redaction, scannable QR payload forensics, and transparent privacy assistance. All execution occurs in ephemeral RAM with zero cloud telemetry.

SOLUTION OVERVIEW

The ShareSafe Two-Pillar Defense Model

ShareSafe operates on a fundamental architectural principle: privacy tools must never compromise privacy during processing. By executing 100% locally on the user's host environment or in an ephemeral serverless container without external cloud API dependencies, ShareSafe eliminates third-party data transmission risks while delivering enterprise-grade document redaction.

Pillar A: Document Privacy Protection

Focuses on the mechanical, automated, and irreversible sanitization of outbound documents. Extracts text streams, validates checksums, locates bounding boxes, scrubs metadata, and permanently eradicates sensitive data before files leave your possession.

PyMuPDF Native Windows / Tesseract OCR Verhoeff / ITD Checks OpenCV QR Decoder

Pillar B: Intelligent Privacy Assistant

Focuses on the cognitive and contextual interpretation of privacy risks. Explains why detected items are sensitive, evaluates disclosure severity based on sharing context, provides actionable recommendations, and guides users through review.

Deterministic Rule Engine Sharing Context Adaptation Explainability Matrix Zero External API Calls
PART A • IMPLEMENTED WORKFLOW

Document Privacy Protection Pipeline

ShareSafe implements a rigorous, nine-stage document privacy lifecycle engineered to ensure that every sensitive byte is detected, confirmed, interactively reviewed, and permanently purged:

01

Secure Ingestion & Magic-Byte Verification

When an image (PNG, JPG, WEBP, BMP) or PDF document is selected or dropped onto the workbench, the backend inspects the raw file magic bytes (e.g. %PDF-, \x89PNG, \xFF\xD8\xFF) rather than trusting client-provided file extensions. Uploaded payloads are bounded by a strict 50-page processing safeguard and stored in isolated, ephemeral per-session storage directories.

02

Dual-Engine Text & Symbol Extraction

ShareSafe incorporates a hybrid extraction architecture tailored to document structure:

  • Digital PDFs: PyMuPDF (fitz) extracts vector glyphs, fonts, and exact bounding box coordinates directly from page content streams with zero loss of fidelity.
  • Scanned Documents & Images: An adaptive OCR pipeline (leveraging Windows Native OCR PowerShell hooks or Tesseract OCR) extracts text lines and word-level coordinate polygons.
03

Context-Aware Algorithmic Entity Detection

Rather than relying on fragile naive regex patterns that trigger false alarms on ordinary numbers, ShareSafe integrates context-aware detectors with statutory mathematical checksum algorithms:

Aadhaar: Verhoeff Checksum Dihedral Group D5 PAN: 4th-Char ITD Entity Check (P, C, H, F, A, T, B, L, J, G) Payment Cards: Luhn Mod-10 Checksum & BIN Validation Contact Info: RFC 5322 Email & E.164 Phone Validation
04

QR Code Payload Forensic Inspection

Embedded QR codes represent a dangerous blind spot in document security because human eyes cannot read them. ShareSafe uses OpenCV computer vision detectors to locate QR codes, decode their raw byte streams, and classify payload contents (e.g. UPI payments, Wi-Fi keys, vCards, or standard URLs). This ensures safe URLs are not falsely penalized while payment routing codes are appropriately flagged.

05

Calibrated Executive Risk Scoring

The RiskAssessor module calculates a composite threat score (0–100) and assigns an executive severity status (Critical, High, Medium, Low). Scores are dynamically adjusted based on the user's chosen sharing context (Academic, Enterprise, Private, Public), deduplicated to prevent score inflation, and bounded by mathematically sound threat ceilings.

06

Interactive Workbench & Custom Manual Drawing

Detected entities are rendered on an interactive canvas overlay with bounding boxes matching document coordinates. Users can toggle individual findings, select categories in bulk, or activate the Draw Manual Box tool in the toolbar to drag custom redaction polygons over handwritten signatures, medical stamps, or proprietary logos.

07

Multi-Style Redaction Rendering

Users can customize the visual redaction style to match the document's aesthetic and regulatory requirements:

Blackout

Total solid black burn-in. Maximum regulatory compliance; zero pixel reconstruction possible.

Gaussian Blur

High-sigma blur destroying high-frequency glyph details while maintaining document flow.

Pixelate

Subsampled pixelation mosaic obscuring sensitive digits in screenshots and technical documents.

Synthetic

Replaces sensitive numbers with clean masked markers (e.g. •••• •••• 0123).

08

Before / After Interactive Split Comparison

To give users absolute confidence before exporting, the workbench provides a synchronized Before / After Split Reveal Slider and side-by-side comparison mode. Users can drag the vertical divider across any page to visually verify that sensitive content is obscured while surrounding non-sensitive text remains intact.

09

Irreversible Sanitization, Metadata Stripping & Audit Certificate

During final export, the redactor performs true irreversible burn-in: rasterizing redacted regions to destroy underlying text layers, stripping all EXIF and PDF document metadata dictionaries, and generating a cryptographically signed SHA-256 Audit Certificate verifying that the sanitized document has been purged of sensitive markers.

PART B • IMPLEMENTED CAPABILITY

The Intelligent Privacy Assistant

While the redaction pipeline provides the mechanical tools to alter files, users frequently struggle with the decision-making process: Is this telephone number sensitive in a public assignment? Should this QR code be blacked out? Is this 12-digit number an Aadhaar card or just an invoice code?

The Intelligent Privacy Assistant (implemented in core/privacy_assistant.py) acts as an on-device expert advisor that analyzes detected entities, assesses contextual risk, and generates human-readable, transparent guidance.

Why Each Item is Sensitive

Explains the statutory or personal significance of detected data in simple, non-jargon language (e.g. explains that Aadhaar exposes government identity credentials that could enable synthetic identity theft).

Potential Risk in Plain Language

Describes what an adversary could do with the exposed item in the specific sharing context (e.g. unsolicited spam, credential harvesting, or infrastructure reconnaissance).

Actionable Recommendations

Categorizes each item into one of three definitive actions: REDACT (immediate removal advised), REVIEW (manual human inspection recommended), or LEAVE (safe to keep unredacted).

Priority & Confidence Calibration

Explicitly separates confirmed statutory matches from uncertain OCR readings. Items with unverified checksums or OCR variances are flagged as Uncertain / OCR Review rather than presenting false alarms.

Comparing Document Privacy and AI Assistance

It is crucial to understand that Document Privacy and AI Assistance serve distinct yet highly complementary roles in ShareSafe:

Functional Dimension Document Privacy Protection (Pillar A) Intelligent Privacy Assistant (Pillar B)
Primary Objective Mechanical detection, obscuration, and irreversible sanitization of file bytes. Cognitive guidance, risk explainability, and informed user decision support.
Direction of Focus Outbound documents prepared for sharing or distribution. Understanding exposure risks and evaluating ambiguous content.
Input Types Raw image pixels, PDF page streams, and embedded metadata bytes. Extracted entity types, confidence metrics, coordinates, and sharing context.
Primary Output Sanitized PDF/image file, stripped metadata, and SHA-256 certificate. Structured recommendation cards, priority badges, and narrative summaries.
Execution Nature Algorithmic computer vision, OCR, vector clipping, and raster burn-in. Deterministic expert rules, contextual weighting, and explainability matrices.
Data Retention Zero retention; processed in ephemeral per-session RAM. Zero retention; executes 100% locally with zero cloud API calls.

Technical Boundaries & Non-Exaggerated Claims

  • No Infallible AI Guarantees: ShareSafe does not claim that AI can guarantee scam detection or ascertain an author's deceptive intent with 100% mathematical certainty. The assistant is designed as an advisory decision-support system, not an autonomous censor.
  • Strict Local Processing: The current implementation uses a local deterministic rule engine in Python. It does not transmit document text, extracted PII, or images to external cloud LLM providers (e.g. OpenAI or Google Gemini), ensuring that sensitive data never leaves your device.
  • Document Integrity: Accepting an assistant recommendation stages the finding for redaction preview on the canvas. It does not alter or overwrite the user's original source file on disk.
