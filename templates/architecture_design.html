System Technologies & Implementation

Core verified technologies and local libraries powering ShareSafe.

Frontend

Jinja2 templates, vanilla JavaScript, HTML5 Canvas crosshair tool, and interactive Before/After split comparison slider.

Backend

Python 3.10+ / 3.13 and Flask 3 web framework managing session routing, magic-byte validation, and 30-minute ephemeral sandboxing.

APIs and integrations

Internal RESTful JSON endpoints (/upload, /api/redact, /api/assistant/decision) operating strictly locally with zero external APIs.

AI Assistance

Deterministic PrivacyAssistant engine providing context-aware risk evaluations across academic, professional, private, and public sharing scenarios.

OCR and detection mechanisms

Dual-engine PyMuPDF vector parser, Windows Media OCR / Tesseract, OpenCV QR threat inspector, and Verhoeff/Luhn checksums.

File processing and sanitisation

Destructive raster burn-in across 5 styles, page.apply_redactions() vector stream purge (0 extractable characters), and ReportLab SHA-256 audit certificates.

Data flow and security architecture

100% on-device processing model: ephemeral UUID session storage, non-recoverable pixel flattening, zero cloud telemetry, and automated memory cleanup.
