Layer 02

Application Layer

Backend Ephemeral Orchestration & Routing

Flask 3 Web Framework

Python 3.13 • app.py

Manages RESTful JSON endpoints (/upload, /api/redact, /api/assistant/decision), request lifecycle, and local zero-telemetry routing.

Ephemeral Session Manager

core/cleanup.py

Isolates every upload in a cryptographically unique ephemeral UUID directory. Enforces strict TTL timeout cleanup with zero database persistence.

MIME & File Ingestion Engine

core/scanner.py

Validates magic-byte signatures and normalizes multi-page PDFs, PNGs, JPEGs, TIFFs, and WebPs into high-DPI rendering rasters.

2. Ingested Stream — Decoded Document Bitmaps & Extracted Vector Blocks
Layer 03

Detection Layer

Multi-Engine Text & Visual Forensics

Dual-Mode OCR Engine

core/ocr_engine.py

Native Windows Media OCR (hardware-accelerated) with automated Tesseract (pytesseract) fallback for scanned images and mobile captures.

Native PDF Vector Parser

PyMuPDF (fitz)

Direct text block parsing and boundary coordinate extraction from searchable PDF vector layers with sub-pixel precision.

Contextual Regex Engine

core/regex_detector.py

Pattern analysis with statutory checksums: Verhoeff algorithm for Aadhaar, Luhn mod-10 for credit cards, ITD for PAN, plus phone/email/IP.

OpenCV QR Forensics Decoder

core/qr_detector.py

cv2.QRCodeDetector localizes 2D barcodes, maps geometric bounding polygons, decodes UPI/URL payloads, and flags leak risks.

3. Structured Findings — Entity Coordinates, Checksum Verifications & QR Payloads
Layer 04

Intelligence & Protection Layer

Contextual AI Reasoning & Irreversible Sanitisation

PrivacyAssistant Decision Matrix

AI Core
core/privacy_assistant.py

Deterministic reasoning engine scoring sensitivity across Academic, Professional, Private, and Public scenarios into actionable priority tiers.

Destructive Raster Redactor

core/redactor.py

Irreversible OpenCV & Pillow pixel burn-in: Gaussian Blur, Hide (Blackout), Whiteout, and Pixelate with zero reverse-engineering vector.

Vector Stream Purge

PyMuPDF apply_redactions

Strips underlying PDF text stream characters and vector glyphs beneath redacted zones to prevent copy-paste pseudo-redaction recovery.

Deep Metadata Stripper

core/metadata_cleaner.py

Wipes EXIF metadata, GPS latitude/longitude, camera serial numbers, thumbnail caches, and PDF author/producer strings.

4. Sanitised File Stream — Zero-PII Flattened Artifacts & SHA-256 Audit Records
Layer 05

Output Layer

Secure Delivery & Ephemeral Lifecycle Completion

Sanitised File Delivery

Protected Export

Delivers true irreversible redacted PDF/image to the client browser, completely sanitized for secure external sharing.

Cryptographic Audit Certificate

core/certificate_gen.py

Generates a ReportLab compliance PDF with SHA-256 integrity hash, redaction tally, timestamp, and verifiable zero-leak audit trail.

Zero-Persistence Shredder

core/cleanup.py

Automatically shreds temporary session folders and cached memory rasters. Zero server retention guarantees absolute privacy.

Closed-Loop Sovereign Privacy: Direct client download completed. Temporary session directories purged immediately with zero persistent database storage and zero cloud telemetry.

System Technologies & Implementation

Frontend

Server-rendered Jinja2 templates styled with a cream/off-white palette, muted rose accents, and teal details. Reactive client interactions via vanilla JavaScript (app.js, canvas_editor.js), HTML5 Canvas for bounding box annotations, and synchronized Before/After visual split comparison.

Backend

Python 3.13 and Flask 3 web framework managing session routing, multi-page document pagination, magic-byte MIME validation, and automated ephemeral session lifetime controls.

APIs and integrations

Internal RESTful JSON endpoints (/upload, /api/redact, /api/assistant/decision, /api/update_ocr_path, /api/download_certificate) operating locally with zero external third-party API dependencies or cloud telemetry.

AI Assistance

Local, deterministic PrivacyAssistant engine (core/privacy_assistant.py) providing context-aware risk analysis across academic, professional, private, and public sharing scenarios. Prioritizes findings into High Priority, Review Recommended, and Informational tiers with clear rationale.

OCR and detection mechanisms

Dual-backend OCR engine supporting native Windows Media OCR runtime and Tesseract OCR (pytesseract). Contextual regex engine with statutory checksum validation (Verhoeff for Indian Aadhaar, Luhn mod-10 for payment cards, ITD entity format for PAN, phone numbers, emails, IPv4 addresses, and cloud API keys). OpenCV QR detector (cv2.QRCodeDetector) for QR localization and payload decoding.

File processing and sanitisation

PyMuPDF for PDF vector text parsing, bounding box extraction, and underlying text stream purge. OpenCV and Pillow for permanent raster burn-in (Blur, Hide/Blackout, Whiteout, Pixelate). Metadata cleaner (core/metadata_cleaner.py) removing EXIF tags, GPS coordinates, and camera history. ReportLab for generating audit certificates.

Data flow and security architecture

Strict on-device processing model: uploaded files exist only in ephemeral, isolated session directories with automated cleanup (core/cleanup.py). True irreversible sanitization permanently overwrites pixels and strips text stream layers to prevent pseudo-redaction recovery, operating with zero cloud telemetry.
