Five-Stage Processing Architecture

Verified architectural stages and responsibilities across the local redaction pipeline:

Stage 01

File Upload

Client-Side Ingestion & Session Isolation

Jinja2 Web Interface

templates/ • CSS3

Provides a responsive drag-and-drop client interface for uploading documents and images.

Flask Ingestion Router

Python 3.13 • app.py

Validates file MIME magic bytes and manages stateless request routing.

Ephemeral Session Isolation

core/cleanup.py

Isolates uploads in temporary UUID session folders with zero persistent database storage.

1. Uploaded File Stream — Normalized High-DPI Rasters & Vector Blocks
Stage 02

Text Extraction & Detection

Multi-Engine Optical & Algorithmic Inspection

PyMuPDF Vector Parser

fitz.open()

Extracts exact text strings and sub-pixel coordinates directly from native PDF streams.

Dual-Mode OCR Engine

core/ocr_engine.py

Performs local optical character recognition via Windows Media OCR with Tesseract fallback.

Contextual Regex Engine

core/regex_detector.py

Detects PII using statutory checksum algorithms including Verhoeff for Aadhaar and Luhn for cards.

OpenCV QR Forensics

core/qr_detector.py

Localizes and decodes 2D barcode matrices to reveal embedded payment and URL payloads.

2. Extracted Findings — Sensitive Entity Tokens, Bounding Boxes & Checksum Proofs
Stage 03

Privacy Risk Review

Context-Aware AI Guidance & Interactive Decisions

PrivacyAssistant Matrix

AI Core
core/privacy_assistant.py

Scores sensitivity across Academic, Professional, Private, and Public contexts into actionable priority tiers.

Interactive Canvas Editor

static/js/canvas_editor.js

Empowers users to review AI detections, draw manual bounding boxes, and confirm redactions.

Split Comparison Viewer

static/js/app.js

Provides a synchronized Before/After split preview to verify changes before export.

3. Confirmed Actions — User Directives: Blur, Hide, Remove, Keep
Stage 04

Blur / Hide / Remove / Keep

Destructive Pixel Burn-In & Layer Purging

Destructive Raster Redactor

core/redactor.py

Permanently overwrites pixels with Gaussian blur, solid blackout, whiteout, or pixelation.

Vector Stream Purge

PyMuPDF apply_redactions

Strips underlying text stream character bytes beneath redacted zones to prevent copy-paste recovery.

Metadata Sanitiser

core/metadata_cleaner.py

Strips EXIF data, GPS coordinates, camera serials, and author metadata from exported files.

4. Sanitised File Stream — Zero-PII Flattened Artifacts & Cryptographic Audit Hash
Stage 05

Protected File Export

Client Download & Zero-Retention Purge

Sanitised File Delivery

Protected Download

Delivers the irreversibly redacted document directly to the client browser for safe external sharing.

Cryptographic Audit Certificate

core/certificate_gen.py

Generates a ReportLab compliance PDF with SHA-256 session hash, redaction tally, and audit timestamp.

Zero-Persistence Shredder

core/cleanup.py

Purges all temporary session files immediately with zero server retention and zero telemetry.

Closed-Loop Sovereign Privacy: Protected export is delivered directly to the user, and temporary session files are purged immediately with zero cloud retention.

System Technologies & Implementation

Core verified technologies and local libraries powering ShareSafe.

Frontend

Jinja2 templates, vanilla JavaScript, and HTML5 Canvas for interactive bounding box redactions and split comparison.

Backend

Python 3.13 and Flask 3 managing session routing, magic-byte validation, and automated ephemeral session lifetime controls.

APIs and integrations

Internal RESTful JSON endpoints (/upload, /api/redact, /api/assistant/decision) operating strictly locally with zero external APIs.

AI Assistance

Deterministic PrivacyAssistant engine providing context-aware risk evaluations across academic, professional, private, and public sharing scenarios.

OCR and detection mechanisms

Windows Media OCR and Tesseract paired with contextual checksum regex (Verhoeff for Aadhaar, Luhn for cards) and OpenCV QR decoding.

File processing and sanitisation

PyMuPDF for vector stream purging, OpenCV and Pillow for permanent raster burn-in, and ReportLab for cryptographic audit certificates.

Data flow and security architecture

Strict on-device processing model: uploaded files exist only in ephemeral, isolated session directories with automated cleanup and zero cloud telemetry.
