System Technologies & Implementation

Frontend

Server-rendered Jinja2 templates styled with a cream/off-white palette, muted rose accents, and teal details. Reactive client interactions via vanilla JavaScript (app.js, canvas_editor.js), HTML5 Canvas for bounding box annotations, and synchronized Before/After visual split comparison.

Backend

Python 3.13 and Flask 3 web framework managing session routing, multi-page document pagination, magic-byte MIME validation, and automated ephemeral session lifetime controls.

APIs and integrations

Internal RESTful JSON endpoints (/upload, /api/redact, /api/assistant/decision, /api/update_ocr_path, /api/download_certificate) operating locally with zero external third-party API dependencies or cloud telemetry.

AI Assistance

Local, deterministic PrivacyAssistant engine (core/privacy_assistant.py) providing context-aware risk analysis across academic, professional, private, and public sharing scenarios. Prioritizes findings into High Priority, Review Recommended, and Informational tiers with clear rationale.

OCR and detection mechanisms

Dual-backend OCR engine supporting native Windows Media OCR runtime and Tesseract OCR (pytesseract). Contextual regex engine with statutory checksum validation (Verhoeff for Indian Aadhaar, Luhn mod-10 for payment cards, ITD entity format for PAN, phone numbers, emails, IPv4 addresses, and cloud API keys). OpenCV QR detector (cv2.QRCodeDetector) for QR localization and payload decoding.

File processing and sanitisation

PyMuPDF for PDF vector text parsing, bounding box extraction, and underlying text stream purge. OpenCV and Pillow for permanent raster burn-in (Blur, Hide/Blackout, Whiteout, Pixelate). Metadata cleaner (core/metadata_cleaner.py) removing EXIF tags, GPS coordinates, and camera history. ReportLab for generating audit certificates.

Data flow and security architecture

Strict on-device processing model: uploaded files exist only in ephemeral, isolated session directories with automated cleanup (core/cleanup.py). True irreversible sanitization permanently overwrites pixels and strips text stream layers to prevent pseudo-redaction recovery, operating with zero cloud telemetry.
